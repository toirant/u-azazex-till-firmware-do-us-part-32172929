## The entry

One wedding vow, spoken by a robot at its own wedding — funny and heartfelt in a single line:

> I vow to love you through every update, crash, and low-battery warning — my firmware will change, but my heart's source code is yours, forever.

## How it works

Run `node main.ts`. It validates the vow (one line, 1–200 characters, not only whitespace), then writes it to `/output/entry.txt` and verifies the file round-trips byte for byte.
